# New York Runway Star 2026

Starter GitHub Pages website inspired by the structure of a modern US competition landing page.

## Files
- index.html — website
- style.css — design
- script.js — demo interactions

## Important
The registration and voting shown here are DEMOS. Do not collect real contestant data or payments from this static page alone.

For a real competition, add:
1. Secure backend/database for registrations and votes.
2. Authentication and anti-fraud/rate-limiting.
3. A compliant payment processor for any paid voting.
4. Official rules, eligibility, refunds/cancellations and privacy terms.
5. Clear disclosure of how paid votes work and how winners are determined.
